# Design Standards Review — pwa-sites (ministry + nonprofit)

Method: rampstack `design-standards` (tokens, WCAG AA contrast, hierarchy, spacing, mobile, component consistency). All contrast ratios computed from the actual token values; responsive behavior verified in a live browser at 375 / 780 / 900 / 1030 / 1440 px against the running server. Visual fidelity to the approved artboards was respected — every fix below is a token/level correction, not a redesign.

Paths are relative to repo root (`/Users/justinokamoto/code/apps/pwa-sites`). Line numbers from current files.

## P1 — blockers

- **P1 · `sites/nonprofit/styles.css:374-384`** — Desktop nav overflows between 769px and ~905px: the hamburger only activates at ≤768px but the full menu (6 links + CTA + brand) needs ~905px. Verified at 780px: "Book a Free Assessment" is clipped off the right edge and unreachable; "Contact" partially cut. Ministry collapses at 1024 and is fine (fits from 1025px up). Fix: move `.nav__toggle { display:block }` and the `.nav__menu` collapse block from the `@media (max-width: 768px)` query into the `@media (max-width: 1024px)` query (mirror `sites/ministry/styles.css:385-395`).
- **P1 · `sites/ministry/styles.css:46-50` + `sites/nonprofit/styles.css:44-48`** — `.btn--secondary` renders white 15–17px text on the sky-400→sky-500 gradient: contrast 2.02–2.53:1 vs required 4.5:1. This is the main conversion CTA on every page (hero "Book a Free Ministry Assessment", featured plan "Start with River", footer CTA). Fix without leaving the sky family: `background: linear-gradient(180deg, var(--color-sky-600), var(--color-sky-700))` (white on sky-700 = 4.80:1) — or keep the light gradient and set `color: var(--color-navy-900)` (6.9:1 on sky-400).
- **P1 · `sites/ministry/styles.css:130` + `sites/nonprofit/styles.css:100`** — Sky-400 `.accent` headline spans on WHITE heroes = 2.02:1 (large text needs 3:1); the marquee phrase is the lowest-contrast text on the page. Affects ministry `pricing.html:68`, `services.html:68`, `contact.html:68`, `our-heart.html:70` and nonprofit `index.html:124` ("Get ready for funding."), `services.html:69`, `pricing.html:69`, `about.html:70`, `contact.html:69`. Fix: on light backgrounds use sky-600 (3.37:1 on white): ministry `.page-hero h1 .accent { color: var(--color-sky-600); }` (keep sky-400 for `.hero h1 .accent` on navy — 6.9:1 there); nonprofit: add `.page-hero .accent, .hero .accent { color: var(--color-sky-600); }` since its heroes are light.

## P2 — should fix

- **P2 · `sites/nonprofit/*.html:29`** — `<link rel="stylesheet" href="/styles.css">` plus root-absolute nav links (`/`, `/services`, `/#faq`) resolve only under host-header routing; at the documented local path `/nonprofit/…` the stylesheet 404s and the whole site renders unstyled, and nav links dead-end at the server root. Ministry uses relative `styles.css`/`services` and works in both environments. Fix: switch all five nonprofit pages to relative hrefs, matching ministry.
- **P2 · `sites/ministry/styles.css:334` + `sites/nonprofit/styles.css:314-318`** — Form inputs/selects/textareas are 15px; iOS Safari auto-zooms any focused field under 16px. Fix: `font-size: 16px` (or `max(16px, var(--text-base))`) on `.form-field`/`.form__field` controls.
- **P2 · `sites/ministry/styles.css:335` + `sites/nonprofit/styles.css:316-317`** — Input borders use `--color-neutral-200` = 1.51:1 against white (UI component boundary needs 3:1) — the exact "light borders on form fields" failure the standard calls out. Fix: `border-color: var(--color-neutral-500)` (4.2:1); keep the sky focus border/outline on focus.
- **P2 · inline section padding defeats the 768px media query (inline > media query):**
  - `sites/nonprofit/pricing.html:74` — `style="padding: 64px 48px 100px"` keeps 48px gutters at 375px: price cards render 279px wide vs the 335px every other section gets.
  - `sites/nonprofit/services.html:151`, `about.html:131`, `pricing.html:162` — CTA sections `style="…padding: 0 48px 100px"` keep 48px mobile gutters.
  - `sites/ministry/our-heart.html:65` — hero `style="padding: 164px 48px 88px"` persists at 375px (every other ministry subpage hero becomes 116px/20px).
  - `sites/ministry/index.html:255`, `services.html:162`, `pricing.html:167`, `our-heart.html:147` — `.cta-section` inline `padding-top: 100px` stays 100px on mobile while sibling sections drop to 72px.
  - Fix: replace inline padding with modifier classes included in the 768px override (e.g. `.section--pricing-top`, `.cta-section--gap`; reuse `.page-hero` for the our-heart hero).
- **P2 · `sites/ministry/styles.css:235-240` + `sites/nonprofit/styles.css:203-208`** — "Most Popular" flag: white 12px/700 on the sky gradient ≈ 2.3:1. Fix: same gradient darkening as the `.btn--secondary` fix, or `background: var(--color-navy-900)`.
- **P2 · `sites/ministry/styles.css:370`** — `.footer-copy` rgba(255,255,255,0.4) at 13px on navy-900 = 3.40:1 (needs 4.5). Nonprofit's footer uses 0.55 (5.17:1) and passes. Fix: `rgba(255,255,255,0.55)`.
- **P2 · `sites/ministry/styles.css:266` + `sites/nonprofit/styles.css:231`** — `.step-num` sky-400 on neutral-50 = 1.86:1, and the number is the only sequence indicator (ministry church-bookkeeping numbers are not aria-hidden). Fix: `color: var(--color-sky-600)` (≈3.1:1, passes as 44px/800 large text).
- **P2 · `sites/nonprofit/index.html:233-272` vs `sites/nonprofit/pricing.html:76-157`** — Home pricing section and the pricing page contradict each other: Starter/Launch/Managed ($800 ≈ "~80 hrs", "$10/hr" rate card) vs Spring/Stream/River/Ocean/Ocean Plus/Ocean Enterprise ($800 = 68 hrs ≈ $11.76/hr). A board comparing the two pages sees two different price lists on one site. Fix: reconcile to one package set and one hours-per-dollar math.

## P3 — polish

- **P3 · `sites/ministry/styles.css:407-409`** — Mobile vertical rhythm only tightens `.section` (→72px); `.section--tight`/`.section--88`/`.section--tint` keep 96/88px at 375px, so church-bookkeeping never tightens while every other page does. Fix: add those classes to the mobile vertical-padding rule (e.g. 64–72px).
- **P3 · `sites/ministry/styles.css:104-108` + `sites/nonprofit/styles.css:92-96,120`** — Eyebrow chips / hero pill: sky-700 on sky-50 = 4.40:1 at 12–13px, just under 4.5. Fix: `color: var(--color-sky-800)`.
- **P3 · `sites/ministry/styles.css:9` + `sites/nonprofit/styles.css:9-11`** — Focus ring sky-500 on white = 2.53:1 (focus indicator should hit 3:1 non-text). Fix: `outline: 2px solid var(--color-sky-700)`.
- **P3 · touch targets** — `.btn--sm` is 34px tall (nav CTA on every page, footer "Book Your Free Assessment"; `ministry/styles.css:38`, `nonprofit/styles.css:36`); footer/social links ~20px tall at 12px gaps (`ministry/styles.css:362`); mobile-menu links 41px. Standard is 44×44. Fix: in the mobile media queries give menu items and footer CTAs `min-height: 44px`; desktop visuals unchanged.
- **P3 · `shared/js/site.js:46-55` + `.reveal { opacity: 0 }` (`ministry:376`, `nonprofit:355`)** — If site.js fails to load, all `.reveal` content stays invisible (nonprofit index has 27 reveal blocks). Fix: inline `document.documentElement.classList.add('js')` in `<head>` and scope to `.js .reveal { opacity: 0; … }`.
- **P3 · typography scale bypassed by inline overrides** — `.h-sub`/`.h-mid` re-sized inline per use: `ministry/index.html:124`, `our-heart.html:70`, `contact.html:77,95`, `church-bookkeeping.html:122,131,143,235,252`, `nonprofit/index.html:373`; card `h3` weight restyled inline at `church-bookkeeping.html:178-193`. The named heading classes no longer mean one size. Fix: add variants (`.h-sub--lg`, `.h-quiet`, a bold card-title modifier) and delete the inline styles.
- **P3 · off-token values** — 9px list gaps (`ministry:171`, `nonprofit:218`), 26px/30px paddings (`ministry:155,216,272`), 18px FAQ radius (`ministry:272`, `nonprofit:250`) vs radius tokens 16/20/24, inline `max-width: 840px` (`church-bookkeeping.html:109`) beside eight `.wrap--*` widths (`ministry:15-22`). Fix: snap to `--space-*`/`--radius-lg|xl`; collapse the wrap scale to 3–4 widths.
- **P3 · button-system drift** — Ministry `.btn--hero-ghost` (`styles.css:56-60`, hard-coded 17px) and nonprofit `.btn--glass` (`styles.css:54-58`, duplicates `.btn--lg` metrics) are the same component with two names/specs; ministry buttons have no `:active` pressed state while nonprofit does (`nonprofit:35`). Fix: one shared glass variant; add the `:active` rule to ministry `.btn`.
- **P3 · mobile menu drift + a11y** — Ministry panel rgba(255,255,255,0.97)+blur, no shadow (`styles.css:387-392`; page text ghosts through where backdrop-filter is unsupported) vs nonprofit solid #fff + shadow (`nonprofit:376-381`). Nonprofit toggle lacks `aria-controls` and its menu lacks an `id` (`nonprofit/index.html:102-105` and all pages); ministry has both. Fix: solid background + shadow on both; add `id="nav-menu"`/`aria-controls="nav-menu"` to nonprofit.
- **P3 · `sites/ministry/styles.css:325` + `sites/nonprofit/styles.css:266`** — `.cta-note`/`.cta-panel__note` white at 0.55 alpha, 13px, over the navy→sky gradient measures ≈3.9–4.7:1 depending on horizontal position. Fix: `rgba(255,255,255,0.7)`.
- **P3 · `sites/ministry/styles.css:279` + `sites/nonprofit/styles.css:297`** — `.value-tile p`/`.value-card p` are real body copy at 13px, under the 14px body floor. Fix: 14px.
- **P3 · no current-page state in nav** — All nav links identical on every page (e.g. `ministry/pricing.html:52-60`); users can't see where they are. Fix: `aria-current="page"` on the active link + a weight/underline style.
- **P3 · `shared/ds/tokens/fonts.css:8`** — Google Fonts via `@import` inside a linked sheet creates a serial render-blocking chain (CSS → CSS → font). Fix: `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>` + a direct fonts stylesheet `<link>` in each `<head>`.
- **P3 · `sites/ministry/styles.css:24-27` + `sites/nonprofit/styles.css:13-16`** — `@keyframes pwa-pulse-glow` re-declared in both site sheets; `shared/ds/tokens/motion.css:56-59` already ships it. Fix: delete the local copies.
- **P3 · non-interactive play affordance** — Founder cards render a play-button circle that is not clickable (`ministry/index.html:104-107`, `nonprofit/index.html:211-214`). "Coming soon" label helps, but the control shape invites taps. Fix: keep the placeholder but drop the play-button ring (or add `cursor: default` and reduce its prominence) until the video ships.

## Summary

- Counts: **3 × P1, 8 × P2, 15 × P3.** Verified: no horizontal scroll on any page at 375px; ministry nav fits at 1025px+; all shared assets resolve.
- P1s: nonprofit nav unusable/clipped at 769–905px (collapse breakpoint should be 1024); `.btn--secondary` white-on-sky CTA text at 2.0–2.5:1 on every page's primary conversion button; sky-400 headline accents on white heroes at 2.0:1 across 9 pages.
- All three P1s are token-level one-line CSS fixes (breakpoint move, sky-600/700 substitutions) that preserve the approved artboard look.
